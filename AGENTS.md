# Personal Agent Harness

Este repositório documenta e versiona o núcleo do harness pessoal.
Leia README.md e apenas os documentos pertinentes. `harness/` é uma cópia
versionada; não representa sincronização automática com a home.
Não publique tokens, configs reais de MCP, transcrições, backups ou logs privados.
Mudanças nas skills devem manter coerência com os diagramas e docs.
Use `python3 -m unittest discover -s tests` para verificar o runner.
Não altere a instalação global nem a VPS apenas por editar este repositório.
